# java21-ocp-lab

Hands-on Java project for Oracle Certified Professional Java SE 21 Developer Exam (1Z0-830) preparation.

## Project Purpose

This repository is a clean and chapter-wise practice lab to:
- learn Java SE 21 core concepts,
- write focused examples for exam topics, and
- build confidence through small runnable programs.

## Java Version

- Java 21
- Maven-based project

## How To Run

```bash
mvn clean compile
mvn exec:java
```

The `exec:java` command launches `com.tani.ocp.App`.
